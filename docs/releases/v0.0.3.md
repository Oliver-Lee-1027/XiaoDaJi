# 小妲己 v0.0.3

- 接入本仓库 `Oliver-Lee-1027/XiaoDaJi` 的 GitHub Releases 更新源。
- 在「设置 → 关于」主动检查后续正式版本，支持查看发布说明、下载更新包、校验并安装后重启。
- 统一程序、Windows 文件属性及安装器版本为 `0.0.3`。
- 保留原安装身份、设置、凭据、上下班记录和置物架分区数据。

## 从 v0.0.1 / v0.0.2 更新

这些旧版未配置在线更新源，需要先从系统托盘退出小妲己，再下载 `小妲己-安装包-v0.0.3-x64.exe`，保留原安装位置直接覆盖安装，无需先卸载。

便携用户下载 `小妲己-v0.0.3-windows-x64.zip`，完整解压到新的版本目录后运行 `小妲己.exe`，不要同时运行旧版。不要下载 GitHub 自动生成的 Source code ZIP 作为安装包。

安装 v0.0.3 后，后续更高版本可通过「设置 → 关于 → 检查更新」发现；远端与本机同为 v0.0.3 时不会提示升级。

## 下载校验

`SHA256SUMS.txt` 提供安装器与便携 ZIP 的 SHA-256 校验值。当前程序没有商业代码签名，运行前请核对发布仓库和文件来源。
