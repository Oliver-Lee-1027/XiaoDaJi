# 小妲己 v0.0.2

- 主程序更名为“小妲己.exe”，卸载程序更名为“卸载小妲己.exe”，统一狐狸图标。
- 修正快捷方式、开机启动、应用列表图标与卸载路径，覆盖升级自动清理旧程序文件名。
- 保留设置、凭据、上下班记录和置物架分区数据。
- 增加成品图标校验及中文路径安装/更新回归验证。

## 从 v0.0.1 更新

先从系统托盘退出小妲己，再下载 `小妲己-安装包-v0.0.2-x64.exe`，保留原安装位置直接覆盖安装，无需先卸载。

便携用户下载 `小妲己-v0.0.2-windows-x64.zip`，完整解压到新的版本目录后运行 `小妲己.exe`，不要同时运行旧版。

在线更新尚未启用，本次通过下载安装包升级；不要用 GitHub 自动生成的源码 ZIP 代替 Windows 安装包。
