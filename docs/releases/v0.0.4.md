# 小妲己 v0.0.4

- 修复英文系统/代码页下，安装测试读取中文快捷方式目标变成问号的问题。
- 安装验证与旧品牌快捷方式清理改用 Windows Unicode 快捷方式接口，直接读取原始 `.lnk`，不再通过临时改名规避问题。
- 新增系统/英文进程代码页下的回归，检查中文路径、快捷方式名称、启动参数与工作目录；错误目标和损坏链接仍会被拒绝。
- 兼容 GitHub 上传后移除中文前缀的 ZIP 附件名，仍保留仓库、版本 URL、大小和 SHA-256 校验。
- 统一程序、Windows 文件属性及安装器版本为 `0.0.4`，保留原安装身份、设置、凭据和各类记录。

## 如何更新

- **v0.0.3 正式发布包用户：** 正式发布后可在「设置 → 关于 → 检查更新」发现 v0.0.4。但该旧版只识别完整中文 ZIP 名，而 GitHub 可能移除中文前缀，因此这次请通过浏览器下载安装包，退出程序后保留原路径覆盖安装；不要把“发现新版”当作已完成自动下载。v0.0.4 已兼容此附件名变化，用于后续更新。
- **v0.0.1 / v0.0.2 或未配置更新源的源码构建：** 先从系统托盘退出小妲己，运行 `小妲己-安装包-v0.0.4-x64.exe`，保留原安装位置覆盖安装，无需先卸载。
- **便携用户：** 下载 `小妲己-v0.0.4-windows-x64.zip`，完整解压后运行其中的 `小妲己.exe`；不要同时运行旧版。不要下载 GitHub 自动生成的 Source code ZIP 作为程序安装包。

覆盖安装会保留用户数据。v0.0.4 检查到远端同为 v0.0.4 时，不会提示再次升级。

## 下载校验

`SHA256SUMS.txt` 提供安装器和便携 ZIP 的 SHA-256 校验值。当前程序没有商业代码签名，请核对本仓库和文件来源。

本地隔离测试不等于 GitHub Actions 已通过；发布后仍需实际验证一次 v0.0.3 → v0.0.4 的浏览器下载与手动覆盖升级；v0.0.4 后续版本的真实在线更新闭环也需验收。
