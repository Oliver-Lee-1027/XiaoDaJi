# 使用指南

## 第一次打开

鼠标靠近屏幕顶部的小岛会展开功能面板。左右箭头和底部圆点切换页面；在列表内部滚轮查看更多内容。托盘菜单可打开设置、控制开机启动或退出程序。

设置里的功能显示开关可以隐藏不常用的页面；隐藏页面不等于删除它的数据。

## 邮箱

在「设置 → 邮件」添加完整邮箱地址，选择服务商并填写授权码或 App 专用密码。不要把密码发送到聊天、Issue 或截图里。

| 邮箱 | 获取连接凭据 |
| --- | --- |
| QQ | QQ 邮箱网页版右上角「设置」→「账号与安全」→「安全设置」→「POP3/IMAP/SMTP/Exchange/CardDAV 服务」→开启服务并生成授权码 |
| 163／126 | 邮箱网页版「设置」→「POP3/SMTP/IMAP」→开启 IMAP，并按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版设置中的客户端收发设置；企业管理员可能限制 IMAP 或第三方客户端 |
| iCloud | Apple 账号开启双重认证后，在账号安全页面生成 App 专用密码 |
| Gmail | Google 账号开启两步验证后生成应用专用密码；单位账号可能由管理员禁用此入口 |

以服务商当前页面为准，小妲己设置页也提供对应说明和网页入口。Gmail 在部分网络环境下需要能够访问 Google；小妲己不会替你改变系统网络设置。

连接后读取最近 20 封邮件；运行期间列表最多保留 60 封。新邮件优先通过 IMAP IDLE 接收，并有定期防漏检查；服务器、网络及服务商投递耗时仍会影响实际到达时间。

验证码卡片显示来源与主题，点击即可复制。点邮件列表进入详情，滚轮查看正文；「阅读全文」打开独立阅读窗口。正文内的网页链接交给默认浏览器打开。

## 日程

在「设置 → 日程」选择平台，填写平台提供的 CalDAV 连接信息。只登录或安装飞书、钉钉、企业微信桌面客户端，不会自动授予小妲己日历读取权限。

- 左侧月历选择日期；右侧按时间显示日程，全天安排在前。
- 大卡片显示选中的日程；滚轮只滚动下方列表，点击其他条目切换大卡片。
- 跨天日程会出现在覆盖的日期中。结束时刻按日历提供的数据展示。
- 自动同步默认每 5 分钟进行；点击右上角更新时间可手动刷新月份。
- 提前提醒时间可在设置中选择 5／15／30 分钟；全天安排展示在日历中，不在午夜弹出会议提醒。
- 普通邮件正文中的日期不会加入日程；带日历附件的正式邀请会自动显示。
- 邮件日程右侧的 × 可忽略该日程，停止显示与提醒；在邮件详情或全文窗口选择「恢复日程」可恢复。忽略邮件来源不会删除工作日历中的对应安排。

**当前边界：** 邮件日程依赖当前加载的邮件记录，不是完整邮箱归档；复杂的批量重复规则修改可能提示不支持。日历同步失败会显示错误，不能把“已连接”当成所有日程都已成功同步。程序退出、电脑关机或睡眠期间无法持续接收提醒。

## 音乐、专注、饮水与待办

小妲己是外部播放器的展示与遥控面板，不会独立登录网易云账号或播放在线曲库。大部分播放器通过 Windows 系统媒体会话接入；网易云另有本机播放日志与队列兼容通道，支持普通安装版和 Microsoft Store 商店版的已知数据目录。客户端版本或日志格式变化仍可能影响兼容性。

在「设置 → 音乐与歌词 → 播放来源」选择：

- **自动选择**：跟随正在播放的音乐，保留原有多播放器切换行为。
- **优先网易云音乐**：有有效网易云歌曲（含暂停状态）时优先使用网易云，否则跟随其他播放器。
- **仅网易云音乐**：只显示、控制网易云；不可用时不会自动切换到其他播放器。

音乐面板会显示当前来源，设置中可查看网易云连接状态。提示数据不可读时先确认客户端已启动并播放歌曲；提示未识别数据时可尝试切歌，并检查客户端版本兼容性。只读访问播放日志不会修改网易云文件，也不会提取登录信息。

播放、上下首、拖动进度按当前来源实际支持的能力启用；无法拖动时进度条仅用于显示。网易云本机兼容控制不支持跳转进度；系统会话支持时才可拖动。控制超时不自动重复发送，以免重复暂停或切歌；“已发送网易云控制命令”仅表示命令已投递，不代表客户端确认执行。

歌词匹配依赖歌曲元数据和外部服务，网易云有歌曲 ID 时优先按 ID 获取并缓存；个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

专注与休息需点击开始，结束后可进入下一阶段。饮水可设置目标、单次量、提醒间隔和时段；记录错误可以撤销。待办提醒是可选项，填写任务后通过日期／时间选择器设置，不需要手写时间格式。

## 上下班记录与提醒

在「设置 → 专注与饮水 → 下班」输入 24 小时制的 `HH:MM` 并点击「保存时间」，开启「到点提醒」，勾选需要提醒的星期。默认时间为 18:30、周一至周五；提醒默认关闭，需要自行启用。自动记录上班默认开启。

- 每天第一次启动软件记录上班时间，同一天重启不清零；持续运行跨天后，首次检测到用户操作才创建当天记录，不在零点自动记上班。
- 展开的「下班」页显示今日时长、上班时间、计划下班时间和倒计时；可在页面管理中隐藏或排序，隐藏不关闭提醒。
- 软件开晚了，可在下班设置中手动修正今日上班时间。时间不能晚于当前时间或已确认的下班时间。
- 到点弹窗支持「10 分钟后」和「我下班了」。延后状态会保存，重启不丢失；确认后记录实际确认时间并停止计时，再次启动也不会重新开一班。
- 关闭提醒弹窗不等于确认下班。前一天未确认的记录显示「未确认下班」，不会用退出时间或设定时间伪造下班记录。
- 记录按自然经过时间计算，包含午休、锁屏、睡眠和中途退出；不是实际电脑操作时间，也不是正式考勤。第一版不支持跨午夜夜班、多班次和自动扣午休。
- 通知总开关关闭时不弹下班提醒；退出或关机期间无法提醒，睡眠唤醒后检查当天到点状态，同一次提醒不会反复弹出。系统通知还受到 Windows 自身设置影响。
- 本地 `work.json` 保存设置和历史记录，设置页展示最近 30 条，旧记录仍保留。读取或保存失败时显示错误，不覆盖损坏文件或假报保存成功。

## 置物架分区

置物架最多支持 **6 个分区（含固定的「未分区」）**。点置物架里的「管理分区」，或打开「设置 → 待办与置物 → 置物」，可创建、重命名、调整顺序和删除分区。名称为 1–12 个字符，不允许重名；「未分区」不能删除或重命名。

- 分区标签始终显示在置物架中，点击后直接展示该分区文件；文件区滚轮只滚动本区，不在列表边界误切换功能页面。
- 从电脑拖文件到某个分区标签，就加入该区；拖到文件区加入当前区；快速拖到收起小岛或未命中具体区域时加入「未分区」。支持一次投放多个文件。
- 「添加」选择的文件加入当前分区。同区重复文件不重复添加，同一文件可被不同分区引用。
- 文件右键「移动到分区」调整分类；原有拖出到其他软件的操作保留，不将两种拖动混用。
- 「清空本区」需要再次确认，只移除本区引用。删除分区也需确认，其中条目移回「未分区」。这些操作均不复制、移动或删除硬盘上的真实文件。
- 原文件被移动或删除时，条目保留并提示失效；投放失败原因可到分区设置查看。
- 旧版 `shelf.txt` 自动归入「未分区」，原文件不改写，另存 `shelf-legacy-backup.txt` 备份；新格式为 `shelf-v2.json`。迁移写入失败时保留旧条目供只读查看，并显示错误；新数据损坏时不自动用旧清单覆盖。

## AI 额度

先登录相应工具，再在小妲己 AI 额度设置中识别本机账号。多个账号可分别命名、选择配色并决定是否常驻。Codex、Claude、Kimi 的本机登录由原工具管理，小妲己不会修改它们的配置。

Grok Bot、Gemini 提供各自的连接入口；会话过期时重新连接。额度接口、订阅类型和服务商策略可能变化，未识别或请求失败时应以对应服务的官方页面为准。

## 更新、卸载与数据目录

双击新版 `小妲己-安装包-v版本号-x64.exe`，可通过路径输入框或「浏览…」选择安装文件夹，勾选「创建桌面快捷方式」和「开机自启」，再点击「一键安装」。首次安装默认创建桌面快捷方式、不开机自启；升级默认保留现有选择。安装位置默认为 `%LOCALAPPDATA%\Programs\Daozai`，可改为其他有写入权限的文件夹，用户数据仍保存在 `%APPDATA%\Daozai`。

从 v0.0.1 更新到 v0.0.2：先在托盘菜单退出小妲己，下载安装包并保留原安装位置直接覆盖，无需先卸载。新版安装目录应出现 `小妲己.exe` 和 `卸载小妲己.exe`，旧的 `daozai.exe`、`Uninstall.exe` 会被清理。便携版请解压到新的版本目录，退出旧版后启动新目录中的 `小妲己.exe`，不要把两个版本同时运行。

v0.0.3 正式发布包已接入本仓库的 GitHub Releases，可在「设置 → 关于」主动检查后续正式版本。未配置更新源的 v0.0.1 / v0.0.2 不能通过新增 Release 自动启用更新，请先退出程序，用 v0.0.3 安装包保留原安装位置手动覆盖升级一次。

升级安装保留数据。若提示小妲己正在运行，先从托盘退出，再点击重试。

在 Windows 已安装应用中卸载会移除程序和快捷方式，但保留数据。若要清除账号，先在小妲己设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**窗口没有出现：** 检查托盘是否已有实例、是否在全屏应用中、设置是否启用了全屏隐藏。

**邮箱登录失败：** 确认填的是授权码／App 专用密码、IMAP 已启用、账号没有被管理员限制。

**日程连接成功但没有安排：** 手动同步所选月份，确认平台授权的日历包含该日程；出现错误时保留错误文字即可，不要提供密码。

**验证码没有马上出现：** 确认邮件是否已到达收件箱，而非垃圾箱；检查小妲己是否运行、连接是否正常。

**图标或布局异常：** 反馈 Windows 版本、屏幕缩放比例、显示器数量和截图。截图先遮挡账号、验证码及私人日程。

## 小妲己品牌与升级

应用显示名为“小妲己”，源码根目录名为 `XiaoDaJi`。安装包为 `小妲己-安装包-v版本号-x64.exe`，便携包为 `小妲己-v版本号-windows-x64.zip`。

从 v0.0.2 起主程序文件名为 `小妲己.exe`，卸载程序为 `卸载小妲己.exe`。用户数据继续使用 `%APPDATA%\Daozai`，原有凭据、注册表应用身份和单实例标识不变。覆盖安装会更新自启路径、清理本安装目录旧程序名及指向同一目录的旧品牌快捷方式，不删除用户数据或置物架原始文件。

已关联源码仓库，但当前成品未启用在线更新，关于页的在线更新入口暂停；使用小妲己安装包升级即可。新仓库确定后按 [品牌与发布说明](BRANDING.md) 接入，不会默认安装上游岛仔版本。
