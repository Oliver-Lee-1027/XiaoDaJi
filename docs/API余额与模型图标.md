# API 余额与模型图标（本地定制版）

## 功能范围

- 保留原有 Codex / Claude / Kimi / Grok Bot / Gemini 订阅额度及其 3 分钟刷新逻辑。
- 新增 NewAPI 账户余额，只读 GET `{服务根地址}/api/user/self`。
- 请求头为 `Authorization: Bearer <访问令牌>`、`New-Api-User: <用户 ID>`；令牌是站点个人安全设置中的访问令牌，不一定是调用模型用的 `sk-` Key。
- 剩余 = `data.quota / 换算系数`，已用 = `data.used_quota / 换算系数`。默认系数 500000，可按站点规则修改。
- 总计只是当前剩余 + 累计已用，不代表固定套餐额度，余额不会冒充周期百分比圆环。
- 不支持任意 JS 提取器，也不声称兼容 Sub2API / Token Plan 等不同接口。

## 设置使用

1. 打开岛仔设置 → AI 额度，在新增的 API 区域启用查询。
2. 填写备注、HTTPS 服务根地址、访问令牌、用户 ID。地址不要包含 `/v1` 或 `/api/user/self`。
3. 设置超时（1–120 秒）、自动查询间隔（0–1440 分钟，0 表示只手动查询）、系数及单位。
4. 点击“测试查询”检查结果。测试不会自动保存账户。
5. 点击“保存 API 账户”。多账户中选择“在悬浮窗显示此账户”；也可独立启停监控、刷新、编辑和移除。
6. 点击悬浮窗最右侧余额会打开 AI 额度页的“API 余额”详情；点击左上角“API 余额 / AI 额度”标题可切换回原有订阅页面。

启动后按账户各自间隔调度；0 分钟的账户不会自动查询。手动刷新最少间隔 15 秒；服务错误和限流有退避时间。
尚未成功查询时显示 `—`，真实零余额显示 `$0.00`；失败或数据过期时保留旧余额并加 `*`，悬停查看原因和时间。
低于 0.01 的非零余额显示 `<0.01`，大金额使用 K / M / B 缩写，悬停查看完整金额。
余额保留在内存，重启后需重新查询，不从磁盘恢复旧余额冒充实时值。

## 模型标识

常规 → 当前使用模型，可选择“不显示”、Codex、Claude、Kimi、Grok、Gemini、SV。
SV 使用提供的蓝色原图。此选择仅影响图标，不检测实际模型，不改变任何软件的请求路由或配置，也不自动切换余额账户。
“添加 / 管理自定义标识”支持名称 + 本地图片、编辑、使用和确认删除。
名称 1–20 字符、不能重名；图片 PNG/JPG/WebP，≤2 MB、≤2048×2048，推荐透明 PNG。
图片被等比缩小并转为应用自有 PNG 副本，之后移动原文件不影响显示。删除当前自定义项会改为“不显示”，不会删除原图。
模型名称不常驻占位，悬停图标显示名称。
常驻排列中的模型图标和余额固定在最右侧，沿用极简、全屏隐藏、通知和岛上歌词的原有显示优先级。

## 数据与安全

默认配置目录 `%APPDATA%\Daozai`（设置 `DAOZAI_DATA_DIR` 可隔离测试数据）：

- `api-quota.json`：非敏感账户配置，只有安全凭据引用，无访问令牌。
- Windows 凭据管理器 `Daozai.ApiQuota`：按账户 ID 保存访问令牌。
- `settings.txt` 中 `current_model`：当前手动标识。
- `model-icons.json`、`model-icons/`：自定义名称及应用内图标副本。

只允许 HTTPS，不跳过证书校验，不跟随重定向转发令牌。响应大小有上限；错误信息不回显原始响应、令牌或敏感请求头。
继承现有 HTTPS 代理和 Windows 系统代理探测。更改或删除配置后，过时的查询结果不会写到新账户上。
导出配置或备份图标不会导出令牌；换电脑需重新填写令牌。

## 本地构建与安装

源码文件夹不是安装包，不能直接运行源码根目录的“安装岛仔.cmd”，该脚本需要先有构建好的程序。

1. 安装 Rust stable（MSVC）及 Visual Studio Build Tools 的“使用 C++ 的桌面开发”和 Windows SDK。
2. 新开 PowerShell，进入本项目根目录：

```powershell
cargo test --locked --lib
cargo build --locked --release --bin daozai --target x86_64-pc-windows-msvc
```

3. 生成文件：`target\x86_64-pc-windows-msvc\release\daozai.exe`。
4. 免安装：退出旧版岛仔后直接运行此文件。新功能不会出现在上游旧安装包中。
5. 需桌面和开始菜单快捷方式时，手动运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -SourceExecutable .\target\x86_64-pc-windows-msvc\release\daozai.exe
```

该脚本安装到 `%LOCALAPPDATA%\Programs\Daozai`，并保留原有用户配置。建议安装前备份配置目录；不会在此文档或仓库保存真实令牌。

若已安装 NSIS，还可运行 `scripts/package.ps1` 生成标准安装 EXE 和 ZIP。不要下载安装上游版本来代替本地构建，否则不会包含此次定制。
